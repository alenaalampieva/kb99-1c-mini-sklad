# kb99-1c-mini-sklad
Конфигурация 1С Мини-Склад (в рамках обучения c KB99)

## Что внутри

- Подсистемы: Предприятие; МиниСклад; Бухгалтерия; РасчетЗарплаты; ОказаниеУслуг
- Справочники: Контрагенты; Сотрудники; Номенклатура; Склады
- Документы: Поступление; Реализация
- Регистры накопления: ОстаткиНоменклатуры
- Отчеты: ОборотыПоТоварам (СКД)
- Печатные формы: Реализация (макет «Печать»)

## Как открыть

1. Создать пустую информационную базу.
2. Открыть её в Конфигураторе.
3. Конфигурация → Загрузить конфигурацию из файлов → выбрать папку с файлами репозитория.
4. Нажать F7 — обновить конфигурацию базы данных.
5. Запустить 1С:Предприятие.
