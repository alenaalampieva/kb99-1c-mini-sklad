# kb99-1c-mini-sklad
Конфигурация 1С Мини-Склад (в рамках обучения c KB99)

## Что внутри
- Подсистемы: Предприятие; МиниСклад; Бухгалтерия; РасчетЗарплаты; ОказаниеУслуг
- Справочники: Контрагенты; Сотрудники; Номенклатура; Склады
- Документы: Поступление; Реализация
- Регистры накопления:
  - ОстаткиНоменклатуры (остатки) — количество на складах
  - ПартииНоменклатуры (остатки) — партии и их стоимость для FIFO
  - Продажи (обороты) — количество, выручка, себестоимость по клиентам и мастерам
- Отчёты (СКД): ОборотыПоТоварам; ВыручкаИСебестоимость; ОстаткиНаДату
- Печатные формы: Реализация (макет «Печать»)

## Неделя 3: что реализовано
- Проведение Реализации по трём регистрам; остатки читаются запросом к виртуальной таблице `Остатки` на момент документа (граница «Исключая») с левым соединением и временной таблицей.
- Контроль остатков только при оперативном проведении; управляемая блокировка регистров.
- Списание партий по FIFO с расчётом себестоимости (проверено на примере Радченко, занятия 11–15).
