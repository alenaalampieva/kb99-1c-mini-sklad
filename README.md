# МиниСклад — учебная конфигурация 1С

Учебный проект курса 1С-разработки (kb99). В корне репозитория — выгрузка конфигурации «МиниСклад» в XML, актуальная на последнюю неделю обучения. История развития — в коммитах по неделям.

Автор: Алампиева Алена.

## История по неделям

| Неделя | Что добавлено |
|---|---|
| 1 | Справочники (Номенклатура, Контрагенты, Склады, Сотрудники), документы Поступление и Реализация, подсистемы |
| 2 | Регистры накопления (ОстаткиНоменклатуры, ПартииНоменклатуры, Продажи), проведение документов |
| 3 | 7 отчетов на СКД (ОборотыПоТоварам, ОстаткиНаДату, Материалы, ВыручкаИСебестоимость, РеестрДокументовРеализация, РейтингУслуг/Клиентов, ВыручкаМастеров, Универсальный), печатная форма, списание по FIFO |
| 4 | Подбор товаров в документах, условное оформление списка Номенклатуры, программная проверка заполнения, периодический регистр сведений «Цены» с автоподстановкой цены в Реализацию |

## Как развернуть с нуля

Нужна платформа 1С:Предприятие 8.3.27 или новее (подойдет комьюнити-версия для разработчиков с developer.1c.ru).

1. Скачать репозиторий: зеленая кнопка **Code → Download ZIP** — и распаковать в короткий путь, например `C:\tmp\ms` (путь не должен быть глубоким).
2. В окне запуска 1С нажать **Добавить** → «Создание новой информационной базы» → «Создание информационной базы без конфигурации…» → указать каталог базы.
3. Открыть базу в режиме **Конфигуратор**.
4. Меню **Конфигурация → Загрузить конфигурацию из файлов…** → указать распакованную папку (где лежит `Configuration.xml`) → «Загрузить».
5. На вопрос об обновлении конфигурации базы данных ответить **Да** (или нажать **F7**), в окне реорганизации информации — **Принять**.
6. Запустить **1С:Предприятие** (F5). Данные (номенклатуру, цены в регистре «Цены» и т.п.) ввести вручную — в выгрузке только структура конфигурации, без данных.

Нужна версия на конец конкретной недели — открой историю коммитов (Commits), выбери коммит нужной недели и скачай ZIP оттуда (Browse files → Code → Download ZIP).

## Что нового в неделе 4

- **Подбор товаров** в документах Поступление и Реализация: форма выбора Номенклатуры с множественным выбором, повторный выбор увеличивает количество строки (+1), сумма пересчитывается.
- **Условное оформление** списка Номенклатуры: услуги выделяются цветом, группы — жирным (настройки динамического списка формы списка).
- **Проверка заполнения** в Реализации (`ОбработкаПроверкиЗаполнения`): «Мастер» обязателен только при наличии услуг в документе; запрет выбора группы в табличной части с привязкой сообщения к полю строки.
- **Регистр сведений «Цены»** (периодический, по дням; задание из книги Радченко): измерение Номенклатура, ресурс Цена. Общий модуль `РаботаСоСправочниками.РозничнаяЦена()` получает последнюю цену на дату документа (`ПолучитьПоследнее`), цена автоматически подставляется в Реализацию при выборе номенклатуры и при подборе.
