# Внешняя печатная форма «Акт о списании товаров (кв99)»

Неделя 5 курса kb99. Автор: Алампиева Алена.

Внешняя обработка (`.epf`) для **1С:Управление торговлей 11** на БСП — печатная форма документа **«Списание недостач товаров»**. В этой папке — обработка, выгруженная в XML (корневой файл `АктОСписанииТоваров_кв99.xml`).

## Что печатает

Штрихкод, «Акт о списании товаров № … от …», организация, подразделение, склад, таблица товаров (№, товар, количество, ед.), «Всего наименований», подписи «Ответственный» и «Зав.складом», **причина списания** в рамке.

## Как устроен код

- `СведенияОВнешнейОбработке()` — регистрация в БСП: вид «Печатная форма», назначение `Документ.СписаниеНедостачТоваров`, команда «Акт о списании товаров (кв99)» (использование «ВызовСерверногоМетода», модификатор «ПечатьMXL»).
- `Печать(МассивОбъектов, КоллекцияПечатныхФорм, ОбъектыПечати, ПараметрыВывода)` — формирует табличный документ; каждый документ с новой страницы.
- Макет: если в обработке есть макет «Макет» — используется он (`ПолучитьМакет`), иначе строится программно с теми же именованными областями (Штрихкод, Заголовок, Шапка, ШапкаТаблицы, Строка, Итог, Подписи, Причина).
- Реквизиты документа читаются с проверкой по метаданным, поэтому форма не падает в других версиях УТ.
- Причина списания: реквизит «ПричинаСписания» → «Комментарий» → «СтатьяРасходов».

## Как подключить

1. Собрать `.epf`: Конфигуратор → Файл → Открыть → `АктОСписанииТоваров_кв99.xml` (или открыть готовый `.epf`).
2. В УТ: НСИ и администрирование → Печатные формы, отчеты и обработки → включить «Дополнительные отчеты и обработки» → Дополнительные отчеты и обработки → «Добавить из файла…» → выбрать `.epf` → «Записать и закрыть».
3. Открыть документ «Списание недостач товаров» → Печать → «Акт о списании товаров (кв99)».
